# 서재 · 독서 PWA

txt, docx, pdf, epub, md, html 파일을 읽는 오프라인 독서 앱입니다.

## 파일 구성

```
index.html              화면 구조 (초기 화면 / 서재 / 읽기 / 메뉴 / 설정)
styles.css              디자인 (한지·먹·쪽빛 팔레트, 세 가지 화면 테마)
app.js                  파서, 서재 저장, 목차 인식, 이어 읽기, 시스템 TTS
sw.js                   서비스 워커 (오프라인 동작)
manifest.json           홈 화면 설치 정보
apple-touch-icon-v2.png 아이폰 홈 화면 아이콘 (180×180)
icons/                  안드로이드·PWA 아이콘
```

## 1. GitHub에 올리기

1. 새 저장소를 만듭니다. GitHub Pages를 무료로 쓰려면 Public이어야 해요.
2. zip을 풀고, 안의 파일을 **저장소 최상위에** 올립니다. `icons` 폴더도 함께 올라가야 해요.
3. Settings › Pages에서 Source를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/ (root)`로 선택합니다.
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/`에 접속할 수 있어요.

## 2. 아이폰 홈 화면에 설치

1. **Safari**로 주소를 엽니다. (Chrome에서는 설치가 안 돼요.)
2. 인터넷에 연결된 상태에서 한 번 열고 몇 초 기다려 주세요. 앱 파일과 글꼴이 기기에 저장돼요.
3. 공유 버튼 › **홈 화면에 추가**를 누릅니다.

## 3. 아이콘이 여전히 기본 글자 타일로 나온다면

iOS는 홈 화면에 추가하는 순간의 아이콘을 저장합니다. 그래서 아이콘 파일을 바꿔도 이미 추가한 앱에는 반영되지 않아요.

1. Safari에서 `https://내아이디.github.io/저장소이름/apple-touch-icon-v2.png` 를 엽니다. 쪽빛 바탕에 펼친 책이 보여야 해요.
   - 보이지 않는다면 GitHub 저장소에 해당 파일이 없는 것입니다. 저장소 최상위에 올렸는지 확인해 주세요.
2. 홈 화면의 기존 '서재' 아이콘을 길게 눌러 삭제합니다.
3. Safari에서 주소를 열고 새로고침한 뒤 다시 **홈 화면에 추가**를 누릅니다.

> 주의: 홈 화면 앱을 삭제하면 그 앱 안에 저장된 책과 읽기 위치도 함께 지워질 수 있어요. 중요한 책은 원본 파일을 먼저 보관해 주세요.

## 4. 업데이트하는 법

`sw.js`의 `CACHE` 값을 올린 뒤 다시 올립니다. 예: `seoga-reader-v1.2.1`. 홈 화면 앱은 완전히 닫았다가 다시 열어 주세요.

## 5. 알아 두실 점

- **글꼴**: 고딕은 Pretendard, 명조는 Gowun Batang을 씁니다. 처음 한 번 온라인에서 열면 글꼴이 저장되고, 이후에는 오프라인에서도 같은 글꼴로 보여요. 저장되지 않은 글자는 기기 기본 글꼴로 보일 수 있어요.
- **데이터 위치**: 책과 읽기 위치는 그 기기 안에만 저장됩니다. 기기끼리 동기화되지 않아요.
- **스캔본 PDF**: 글자 정보가 없는 스캔 PDF는 지원하지 않아요.
- **목차 규칙**: `app.js`의 `HEAD_RES`와 `isHeadingLike()`에서 제목 패턴을 고칠 수 있어요.
